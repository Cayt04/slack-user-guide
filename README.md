# slack-user-guide
Portfolio sample: user guides for Slack features

A self-initiated portfolio project showing task-based documentation for Slack. It is not affiliated with or endorsed by Slack.

## Project overview
- **Audience:** Freelancers and small teams new to Slack
- **Goal:** Help a first-time user get started with core Slack features
- **Tools:** Slack (free workspace), Markdown, Git
